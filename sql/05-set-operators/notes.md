집합연산

집합 연산자는 2개 이상의 쿼리 결과를 행 단위로 결합할 때 사용한다.

집합 연산 필수 규칙
- 컬럼의 개수가 같아야 한다. (두 쿼리가 조회하는 컬럼 수가 일치해야 한다)
- 컬럼의 데이터 타입이 호환되어야 한다. (데이터 종류가 같거나 자동 형변환이 가능해야 한다.)

1. UNION(합집합 + 중복 제거)
- 두 쿼리의 결과를 합쳐서 보여주되, 중복된 행은 하나만 남기고 제거한다.
- 실무에서 데이터의 의미가 다른 컬럼끼리 UNION 으로 묶는 경우는 거의 없다. 구조가 완전히 똑같은 테이블이나 쿼리를 위아래로 합칠 때 사용한다.


2. UNION ALL(합집합 + 중복 포함)
- 두 쿼리의 결과를 단순히 위아래로 붙여서 보여준다. 중복을 제거하지 않기 때문에 빠르다.
(중복 데이터가 없거나, 중복을 허용하여 모든 데이터를 보여줄 때, 유리함)

3. INTERSECT(교집합)
- 두 쿼리의 결과 중 공통으로 존재하는 데이터만 가져온다.

4. EXCEPT / MINUS (차집합)
- 첫 번째 쿼리 결과에서 두 번째 결과에 포함된 행을 제외하고 남은 데이터 가져옴

DBMS에 따라 명령어가 다를 수 있음

---

JOIN
- RDBMS에서 두 개 이상의 테이블을 공통된 값을 기준으로 가로로 연결하여 하나의 커다란 통합 데이터로 조회하는 역할을 한다.

- 정보를 분산해서 저장하여 관리하기 쉽게 저장하고, 합칠 때 사용한다.
    - 회원 테이블 : 회원번호, 이름, 이메일
    - 주문 테이블 : 주문번호, 회원번호, 상품명, 주문일자
    이런식으로 테이블을 쪼갠다.

1. INNER JOIN
- 양쪽 테이블에 공통으로 존재하는 데이터를 골라서 연결
- SELECT 컬럼명 FROM 테이블A INNER JOIN 테이블B ON 두 테이블을 연결할 조건
    - 원하는 만큼 계속해서 INNER JOIN 또는 LEFT JOIN을 아래로 이어 붙여 나갈 수 있다.

2. LEFT OUTER JOIN
- 왼쪽에 있는 테이블은 전체 출력을 한다.
- 오른쪽에 있는 테이블은 조건에 맞는 부분을 데이터를 출력하고, 맞지 않으면 NULL를 출력한다.

    

별칭을 사용(AS 생략 사능)
- 별칭을 작성할 때 AS를 사용하여 지정한다.(FROM memebers AS m)
- AS를 생략 가능하다(FROM member m)
    - 관례적으로 첫 글자를 따서 별명을 짓는다.
- 별칭은 테이블이 처음 등장하는 FROM 또는 JOIN 뒤에서 작성한다.

IN
- SQL에서 IN 연산자는 특정 컬럼의 값이 괄호 안에 지정한 값들 중 하나라도 일치하는지 확인할 때 사용하는 조건문이다.
(OR를 간단하게 줄여줌, 서브쿼리와 잘 어울림)
- SELECT * FROM members WHERE member_id IN (SELECT member_id FROM orders);
    - members 중에서 orders의 id와 같은게 있다면 출력
