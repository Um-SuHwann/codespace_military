대부분의 데이터베이스 관리 시스템(RDBMS)는 3단계 계층 구조를 갖는다.
- Database Server: 전체 시스템(MySQL, PostgreSQL 등)
- Database(데이터베이스/스키마): 연관된 프로젝트나 앱단위의 저장공간(1개의 서버 안에 여러 개 생성 가능)
- Table(테이블): 실제 데이터가 저장되는 표 형태의 공간(1개의 DB안에 여러개 생성가능)

---

.sql 파일을 사용
- 터미널에서 sudo mysql < 파일이름 또는 source 파일이름 으로 파일의 첫줄부터 마지막 줄까지 실행 가능
- source를 사용하면, 파일 실행이 끝난 후에도 추가 쿼리를 이어 쓸 수 있다.
(.sql 파일 안의 제일 위에 USE 데이터베이스명; 이 적혀 있어야, 파일 실행이 끝난 뒤 추가로 입력하는 쿼리도 해당 데이터 베이스 안에서 이어진다.)

예약어와 데이터베이스 객체명은 대소문자를 구별하지 않지만, 예약어는 대문자로, 데이터베이스 객체명은 소문자로 표기하는게 관습이다.

열은 하나의 자료형만 가질 수 있다.

---
DESC 테이블명;
테이블을 만든 후, 어떤 컬럼(열)들이 있고 데이터 타입이 무엇인지 테이블의 명세를 조회할 때 사용한다.
- Field: 컬럼 이름
- Type: 데이터 타입
- Null: 빈값(NULL) 허용 여부
- Key: 기본키(PRI - Primary Key) 여부
    - 기본키 : 테이블에서 각 행을 서로 식별할 수 있는 고유한 대표 값이다.(중복불가, 빈 값 불가)
- Extra: 자동 증가(auto_increment) 등 추가 옵션


CHAR형은 고정길이 문자열이 저장되는데, 최대 길이보다 작은 문자열이 저장될 경우에 공백문자로 나머지를 채운 후 저장한다.

---
WHERE 검색조건 지정하기
행을 선택할 때는 WHERE 구를 사용하고, 열을 선택할 때는 SELECT 구를 사용한다.

SELECT 컬럼명1, 컬럼명2 
FROM 테이블명 
WHERE 조건;

1. 비교 연산자 (=, >, <, >=, <=, !=)
2. 다중 조건 연산자 (AND, OR, NOT)
3. 범위 및 목록 연산자 (BETWEEN, IN)
4. 패턴 검색 연산자 (LIKE)
5. 빈 값 조건 연산자 (IS NULL, IS NOT NULL)
NULL를 검사할 때는 = 가 아닌 IS NULL를 사용해야 한다.
