case 문
sql에서 사용하는 조건문이다. 데이터의 값에 따라 조건별로 다른 결과를 반환하고 싶을 때 사용한다.

- CASE 기본 문법
CASE
    WHEN 비교값1 THEN 결과값1
    WHEN 비교값2 THEN 결과값2
    ELSE 기본결과값
END

마지막 ELSE 절은 생략 가능하고, ELSE가 없으면 조건에 맞지 않을 때, NULL를 반환한다.
BUT, NULL값은 오류를 많이 만들기 때문에 ELSE는 생략하지 않는게 좋다.

THEN 뒤에 올 수 있는 것
- 문자열 숫자, NULL
- 다른 컬럼의 값
- 간단한 계산식
CASE문은 테이블에 새로운 행을 추가하는 명령을 실행하는 도구가 아님.
조회할 때, 어떤 값을 보여줄지 결정하는 표현식이다.

CASE문은 조건에 따라 값을 만들어내는 도구 역할이고, SELECT 안에 쓰면 조회, UPDATE와 쓰면 수정에 사용할 수 있다.
