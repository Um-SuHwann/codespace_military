csv파일을 사용한 google stock price 분석


### csv파일 불러오기
- 관계형 데이터베이스에서는 원칙적으로 테이블을 먼저 생성한 뒤 데이터를 넣어야 한다.
    - 데이터 무결성과 검색속도를 가장 중효시 하기 때문에, 데이터를 담기 전에 규칙을 강제한다.

### COMMENT
- MYSQL에서 COMMENT 는 테이블이나 컬럼에 주석을 달아두는 역할을 한다.
    - 테이블 뒤 또는 컬럼 뒤에 COMMENT = '내용' 을 붙여 사용한다.
    - =는 생략하고 COMMENT '내용'으로 사용할 수 있다.
- 데이터에는 영향을 주지 않는다.

### primary key(기본키)
- 테이블에서 각 row를 유일하게 식별하기 위한 컬럼이다.
- primary key는 1개 이상이다.
    - 여러개를 설정하면 복합 기본키가 된다.
- 설정 방법
    - 컬럼 작성시 primary key 작성
    - 테이블 정의 마지막에 primary key() 작성

### CONSTRAINT
- 테이블에 지켜야 할 규칙을 정의한다.
- 주요 제약 조건의 종류
    - PRIMARY KEY(기본키) : 각 행을 고유하게 식별하는 컬럼이다. 중복된 값과 NULL을 허용하지 않는다.
    - NOT NULL : 해당 컬럼에 NULL이 들어오는 것을 금지함.
    - UNIQUE : 컬럼에 중복된 값이 들어오는 것을 방지한다. 모든 행의 값이 고유하다.
    - CHECK(조건확인) : 입력되는 데이터가 특정 조건을 만족하는지 검사한다.
    - FOREIGN KEY(외래키) : 다른 테이블의 기본키를 참조하여 테이블 간의 관계를 연결하고 무결성을 유지한다.
    - DEFAULT(기본값) : 데이터를 삽입할 때 값을 생략하면 자동으로 지정된 기본값이 입력되도록 설정한다.
